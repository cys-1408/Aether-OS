# Miso Animation Spec
Artwork: the approved SVG cat (desktop/assets/miso/miso.svg and state variants). States: idle (tail sway 2s, occasional head tilt 5s), walking (bob 0.5s, tail 1s), running (bob 0.3s), jump (0.65s ease-out arc), searching (tail 0.5s), sleeping (tail 4s, closed eyes), carrying (holds file chip, head steady), pulling/pushing (window maximize/minimize gestures), focused (head steady during focus mode). Rendering: rsvg → cairo on a GtkDrawingArea, transform groups animated at ~30 fps via GLib timeouts; pupils track the pointer with clamped offset. Pointer dragging moves the companion; click toggles the assistant panel. Reduced motion: single static frame (desktop/accessibility/reduced_motion.py). The animation is presentation only — every agent claim is backed by real broker results.
