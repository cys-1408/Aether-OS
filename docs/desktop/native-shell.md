# Native Shell
aether-shell is a GTK3 (PyGObject) desktop process running in a sway session. Panels (top bar, taskbar) use gtk-layer-shell where available, with a documented fallback. It owns: top bar (brand, live status, clock), desktop icons from real desktop entries, launcher with search, window tracking and operations via sway IPC, notification center, activity panel fed by the Action Ledger, focus chip and focus mode (per-window dimming through sway opacity), toasts, settings persistence via GSettings (org.aether.Shell), and the Miso companion view. It also hosts the Shell.* JSON-RPC server (CONVENTIONS §4) that the broker calls for app/window capabilities. The shipped HTML reference is design material only; no browser technology renders the shell.
