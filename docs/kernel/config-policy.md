# Configuration Policy
Configuration is assembled from kernel/configs/aether_defconfig plus topic fragments in kernel/configs/fragments/ merged with scripts/kconfig/merge_config.sh (kernel/scripts/merge-config.sh), which fails on unresolved options. Topics: CPU/scheduler, memory/cgroups, storage/filesystems, networking, DRM, input/HID, audio, security/LSM, namespaces/seccomp, power/thermal, debug. Rules: drivers used by the supported hardware matrix are built (=m) unless needed to mount root (=y); debug noise off; hardening on (fortify, init-on-alloc, stack protector, stricter usercopy). The final .config hash is recorded in kernel/provenance/config-hash.txt at build time.
