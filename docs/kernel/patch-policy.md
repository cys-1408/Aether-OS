# Patch Policy
1.0.0 carries an EMPTY patch series (kernel/patches/series is a documented empty list): Aether's kernel identity comes from configuration, build recipe and user-space integration, not private diffs. Any accepted patch must: fix a demonstrable defect or enable required hardware; be ≤200 lines; carry rationale, upstream status, threat review and a removal path (kernel/patches/README.md template); be applied by apply-patches.sh in deterministic order with recorded digests (provenance/patch-manifest.json). A patch is retired the moment an equivalent lands upstream.
