# Driver Support
Inherited from upstream: storage (NVMe, AHCI, USB storage, SD), filesystems (ext4, btrfs, xfs, vfat, exfat, ntfs3, squashfs, overlayfs), networking (iwlwifi/ath*/r8169/e1000e and USB NICs as modules), graphics (i915, amdgpu, nouveau; simpledrm fallback ensures display in VMs), input (atkbd, libinput-compatible HID), audio (HDA, SOF), power/thermal (ACPI battery, thermal zones), plus linux-firmware where redistributable (boot/firmware-policy). Unsupported hardware is reported truthfully by the probes and documented in docs/hardware/known-limitations.md; there is no fake detection.
