# Upstream Kernel Selection
Aether pins the 6.12 LTS series (kernel/upstream.lock: version, URL, tag, digest slot filled at fetch). Rationale: long-term support, maintained driver set for x86-64 laptops/desktops, cgroup/PSI/landlock maturity required by the resource governor and sandboxing. Selection criteria documented for future bumps: LTS status, driver coverage for the supported hardware matrix, security cadence, toolchain requirements. The exact tree is fetched by kernel/scripts/fetch-upstream.sh and verified by verify-upstream.sh before any build; provenance is recorded by collect-provenance.sh.
