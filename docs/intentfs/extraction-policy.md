# Extraction Policy
Supported extractors: plain text, Markdown, PDF text layer (pdftotext when installed), office documents (docx/pptx/xlsx via zip+XML), source code, filename metadata, image metadata (dimensions, EXIF basics), optional OCR (tesseract). Each declares limits (max size 20 MB default, max extracted chars) from /etc/aether/intentfs.yaml. Extracted text is UNTRUSTED input: it is wrapped in data delimiters for the model and can never alter policy or trigger capabilities (miso/safety). Unsupported formats index filename/metadata only, shown truthfully as pending-limited, never with invented concepts.
