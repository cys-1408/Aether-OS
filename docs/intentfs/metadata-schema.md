# Metadata Schema
SQLite (WAL) per user at ~/.local/share/aether/intentfs/intentfs.db; canonical schema in intentfs/index/schema.sql and migrations/001_initial_schema.sql. Record: stable file_id (dev:inode:size:mtime digest), path, filename, mime, size, mtime, content_hash, extractor_version, model_id, index_status (ready|pending|failed|excluded), concepts JSON (exactly 3 when ready), failure_reason, privacy_scope, indexed_at. The JSON projection is protocols/schemas/intentfs-record.schema.json. Renames preserve file_id; content changes re-index; deletes tombstone per policy. Index operations never modify original file bytes.
