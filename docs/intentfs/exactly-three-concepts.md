# Exactly Three Concepts
For every successfully indexed supported file, the model must produce exactly three distinct, non-empty concepts (2–32 chars) grounded in the file. Generation uses a constrained prompt demanding strict JSON {"concepts":[a,b,c]}; the normalizer trims/lowercases/dedupes; the validator enforces count=3, distinctness, length, language sanity. On malformed output the generator retries up to 3 bounded attempts with tightening feedback; persistent failure marks the record failed with a reason. The UI renders exactly the three concepts for ready records and truthful pending/failed states otherwise. Fabricating concepts is a specification violation.
