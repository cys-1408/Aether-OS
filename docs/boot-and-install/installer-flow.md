# Installer Flow
Screens (installer/screens/): welcome → language/keyboard → hardware requirements (honest pass/fail) → network choice (optional) → target disk (exact device named) → partition plan (auto ESP+root or manual) → encryption (optional LUKS2) → timezone → user account → privacy options → install summary → progress → completion/failure recovery. The destructive-action guard (installer/storage/destructive_action_guard.py) requires the typed disk name and records a pre-install partition-table backup (sfdisk --dump) enabling install_rollback. Installation uses pacstrap with the ISO's local package repo — network and model downloads are NOT required. First boot then runs the first-boot wizard.
