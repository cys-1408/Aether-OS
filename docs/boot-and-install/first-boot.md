# First Boot
aether-firstboot.service launches the GTK wizard when /var/lib/aether/firstboot-state.json is absent or incomplete (system/firstboot/). Pages: locale, keyboard, timezone, account creation (via the polkit account helper), network choice, privacy defaults (writes user overrides of /etc/aether/privacy-defaults.yaml), disk-encryption status (read-only), optional AI setup (runtime recommendation + consent-gated download, or explicit skip → no-model mode), completion. State is resumable; interruption resumes at the last committed page. The wizard never blocks login to a TTY: unsetting the graphical autologin keeps the system usable if setup is skipped.
