# Capability Catalog
Typed actions per group (apps, windows, files, writer, focus, system-status, models, workspaces, settings) live in miso/capability-os/schemas/*.capabilities.json with: id, version, provider, risk_class, permission, timeout, idempotency, side_effects, confirmation policy, input/output schemas, undo. Providers: desktop (Shell socket), system:<service> (broker forwards), agent-local (unprivileged user execution). Authoring guide: miso/capability-os/docs/capability-authoring.md. The catalog is the ONLY surface Miso can call — arbitrary generated commands have no route.
