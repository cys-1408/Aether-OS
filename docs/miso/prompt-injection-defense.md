# Prompt Injection Defense
Defense in depth: (1) file/web content is framed as data with strict delimiters in prompts; (2) an injection filter flags instruction-like patterns in retrieved text and quarantines it from the planner; (3) the model can only emit typed capability requests validated against schemas — never shell strings; (4) arguments are scope-checked (path allowlist, non-sensitive); (5) destructive actions always need human confirmation regardless of model confidence; (6) the agent's own policy/ledger are untouchable. Documented in threat-model (docs/security/prompt-injection.md).
