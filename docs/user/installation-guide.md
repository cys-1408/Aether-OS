# Installation Guide
1. Download the Aether ISO (see release artifacts) and VERIFY its sha256 (checksums file) and signature. 2. Write to USB (dd or Rufus/Ventoy). 3. Boot: UEFI preferred; ensure Secure Boot off unless enrolling custom keys. 4. Choose "Install Aether OS" from the boot menu; the live desktop can be tried without installing. 5. Follow the installer: pick the exact target disk (typed confirmation), optional LUKS2 encryption, create your user, review privacy options. 6. Installation works fully offline; network optional. 7. On first boot the setup wizard resumes/finishes; choose to set up a local AI model now or skip. Verify: after install, `systemctl --failed` is empty and Recovery Center shows the recovery entry.
