# Desktop Guide
Top bar: brand, live status, clock, quick settings. Desktop icons launch real apps; the taskbar shows running windows. Super+d opens the launcher with app and action search. The Miso companion walks, runs, jumps, searches, sleeps and carries; its bubble shows what it is actually doing (from the Action Ledger, never invented). Focus mode dims everything but your chosen window; the focus chip pauses/ends the session. Notification center, activity panel and toasts reflect real system events. Keyboard: everything reachable; reduced motion and high contrast in Settings → Appearance/Accessibility.
