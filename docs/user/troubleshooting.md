# Troubleshooting
Boot failure: use the recovery entry; Bootloader repair / Initramfs rebuild cover the common cases. Service down: System Monitor → Services shows the true state; `journalctl -u aether-<name>` for detail. Miso unresponsive: it fails closed when the broker is down — check aether-broker/aether-health; AI answers unavailable means the Runtime says why (Settings → AI Runtime). Indexing stuck: Settings → IntentFS shows pending/failed with reasons; pause/resume/reindex are real controls. Update interrupted: Recovery → package rollback. Always export a redacted diagnostic bundle before filing an issue.
