# Supported Hardware
Target: x86-64 UEFI (BIOS documented) machines, ≥4 GB RAM (2 GB boots to desktop with software rendering and no model), ≥32 GB storage for install. Graphics: Intel/AMD/NVIDIA via upstream DRM (NVIDIA without proprietary driver = simpledrm/modesetting fallback, honestly reported). Wi-Fi: upstream drivers + linux-firmware. The tested device matrix is maintained in hardware/compatibility/known-devices.yaml; anything else is "expected to work via upstream drivers" without guarantees. Accelerator-based inference requires a supported GPU with free VRAM ≥ model estimate; otherwise CPU inference is used.
