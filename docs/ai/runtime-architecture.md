# Runtime Architecture
aether-runtime is a system service (socket /run/aether/runtime.sock) owning model lifecycle: hardware profile → catalog + compatibility filter → ranked recommendation → explicit consent → resumable download (Range) with HF-API sha256 verification → transactional install into the versioned model store → backend selection (llama.cpp adapter spawning llama-server on loopback, ephemeral port) → warmup + smoke check with measured latency/memory → ready. Queues separate interactive, extraction and background traffic with backpressure from memory PSI; the governor unloads idle models, reduces context, and pauses background work under battery/thermal pressure. The inference API bounds tokens, timeout and context, supports cancellation, and is loopback-only. States and user feedback per state are listed in docs/user/ai-runtime-guide.md.
