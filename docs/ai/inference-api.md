# Inference API
Runtime.infer / Runtime.infer_stream on /run/aether/runtime.sock, JSON-RPC 2.0. Request (protocols/schemas/inference-request.schema.json): request_id, task_class, prompt, max_tokens (≤2048), temperature, stop, timeout_s (≤120), stream, cancellation_token. Response (inference-response.schema.json): state, text, usage {tokens_in, tokens_out, latency_ms}, error. Prompts containing file content must be passed through the Runtime's untrusted-content framing (prompt_builder). The endpoint binds loopback only; remote providers are structurally denied in 1.0.0 (ai/runtime/privacy/remote_provider_consent.py).
