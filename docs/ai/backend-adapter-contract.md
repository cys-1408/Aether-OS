# Backend Adapter Contract
A backend implements: start(model_path, ctx, options) → handle; health() → ready/failed; infer(request) → completion; stream(request, on_chunk); stop(). Registry discovery: llama-server on PATH or /usr/lib/aether/backends. The llama.cpp adapter binds 127.0.0.1 with an ephemeral port, polls /health until ready (60 s timeout), maps stop/cancel by closing the stream, and treats crash as degraded-with-reason. GPU offload is attempted only when an accelerator is detected AND the build reports GPU support; otherwise CPU mode is used and reported truthfully. Adding a backend never touches service code — only the registry.
