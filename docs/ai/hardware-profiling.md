# Hardware Profiling
Facts (measured): CPU model/cores/flags (/proc/cpuinfo, sysfs topology), memory total/available (/proc/meminfo), PSI (/proc/pressure), accelerators via /sys/bus/pci class 0x03/0x12 with driver binding, VRAM where exposed, storage free space, power supply and thermal zones. Estimates (labeled): memory budget = available − OS reserve − desktop reserve; model footprint = weights + KV cache (from GGUF metadata: n_layers, n_embd, head count) + runtime overhead; latency = memory-bandwidth model with uncertainty band. The profile schema is protocols/schemas/hardware-profile.schema.json with explicit unknown_fields for undetected items — nothing is invented.
