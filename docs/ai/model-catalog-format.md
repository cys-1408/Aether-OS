# Model Catalog Format
ai/catalog/catalog.json is a signed-by-digest curated list (schema: ai/catalog/catalog.schema.json). Entry fields: model_id, name, task_classes, repo/file (Hugging Face GGUF), quantization, approx_size_gb (explicitly approximate), license, context_lengths, min_ram_gb, notes. Integrity: catalog.json.sha256 committed and verified at load; optional GPG signature when present. Weights are fetched at download time from the pinned repo; the file digest is obtained from the HF API tree metadata (lfs.sha256) and verified streaming after download — a mismatch aborts the install. No weights ship with the OS.
