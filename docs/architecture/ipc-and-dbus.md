# IPC and D-Bus
Aether v1 uses JSON-RPC 2.0 over unix domain sockets as its local IPC ("equivalent local IPC" per the architecture directive), implemented once in libraries/libaether-core/python/aether_core/ipc.py. Rationale: no hard bus dependency in early boot, trivially testable, SO_PEERCRED gives caller identity, and systemd socket ownership is not required for correctness. Sockets: system services /run/aether/<name>.sock (mode 0660, group-restricted), session services /run/user/$UID/aether/<name>.sock. Method namespaces (Hardware.*, Network.*, Runtime.*, IntentFS.*, Broker.*, ...) are pinned in CONVENTIONS.md §4. The protocols/dbus/*.xml files document each interface as D-Bus introspection XML with an org.aether.Socket annotation mapping it to its UDS path, so any D-Bus tooling can reason about the contract; a D-Bus adapter is an additive future layer (docs/interfaces/compatibility-policy.md).
