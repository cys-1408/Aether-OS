# Data Flow
Desktop ↔ services: the shell polls Health.summary/Audio/Network for the top bar and renders ledger entries in the activity panel. Files → IntentFS: inotify events → normalized jobs → extraction → three-concept generation (Runtime.infer) → SQLite record; queries come from the Files app and Miso. Miso loop: Agent.submit → intent classification → plan (action-plan schema) → broker permission decision → confirmation (if required) → capability dispatch (Shell/system services/agent-local) → result verification → Action Ledger entry → response. Runtime: catalog + hardware profile → recommendation → consent → download (HF sha256 verified) → llama.cpp backend on loopback → bounded inference. Telemetry never leaves the device; network egress from AI capabilities requires Consent.check (services/networking/network-consent).
