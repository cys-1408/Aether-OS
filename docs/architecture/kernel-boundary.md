# Kernel Boundary
The kernel provides scheduling, virtual memory, drivers, VFS and networking exactly as upstream provides them; Aether adds configuration and a small, reviewed patch series (currently empty). All AI is user space: model inference, planning, extraction and policy never run in kernel context, never hook scheduler or allocator paths, and never gate boot. Kernel-side Aether touchpoints are limited to: configuration fragments, provenance collection, and standard observability (PSI, cgroups) consumed by the Runtime resource governor through /proc/pressure. Any future patch must carry rationale, threat review, upstream status and a removal path per kernel/patches/README.md. IntentFS is a user-space service over the normal VFS; it does not implement a kernel filesystem (docs/intentfs/metadata-schema.md).
