# Boot Chain
UEFI (preferred) loads GRUB from the ESP (bootloader-layout.md). GRUB presents entries generated from boot/grub/grub.cfg.in: Aether OS, Aether OS (recovery, booting aether-recovery.target), and Install Aether OS (live installer). The kernel (vmlinuz-aether) plus initramfs-aether.img load from the boot media; cmdline profiles live in boot/kernel-cmdline/. The initramfs init (boot/initramfs/init) mounts dev/proc/sys, runs numbered hooks (device discovery, storage drivers, filesystem drivers, optional LUKS unlock, root selection), mounts the root filesystem — squashfs+overlay for live media, or the installed ext4 root — and calls switch_root. PID 1 is systemd: sysinit.target → multi-user → aether-graphical.target, which starts greetd/sway and the aether service set per system/init/dependency-graph.yaml. Shutdown ordering follows shutdown-order.yaml. Known-good rollback entries are managed by recovery/rollback.
