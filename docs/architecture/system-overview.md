# System Overview
Aether is a local-first, AI-native desktop OS built on a pinned upstream Linux kernel. Layers, bottom-up: (1) firmware/boot (UEFI, GRUB, initramfs); (2) kernel + drivers; (3) base OS (systemd, PAM/logind, NetworkManager, PipeWire, pacman); (4) Aether native platform (sway session, aether-shell, GTK apps); (5) Aether services (hardware probe, storage, networking, audio, time, notifications, logging, backup, health); (6) AI platform (Aether Runtime, model catalog, llama.cpp backend adapter); (7) semantic services (IntentFS); (8) agent platform (Miso, CapabilityOS broker, Action Ledger, Living Workspaces). Services communicate over JSON-RPC 2.0 on unix sockets (docs/architecture/ipc-and-dbus.md). Ownership boundaries and the privileged-action boundary are specified in privilege-boundaries.md; failure behavior per service is mapped in failure-domains.md. Core OS function never depends on a running model: login, files, terminal, networking, updates and recovery all operate with AI fully unavailable.
