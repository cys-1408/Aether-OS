# Process and Service Map
System services (dedicated users, hardened units): aether-hardware-probe, aether-power-manager? (power-manager), aether-broker, aether-runtime, aether-intentfs, aether-ledger, aether-workspace, aether-notification, aether-update-check, aether-health, aether-backup, aether-recovery, aether-firstboot, aether-cleanup, aether-network-policy, aether-session. User-session services: aether-shell (the desktop), aether-agent (Miso). Each owns one unix socket under /run/aether/ or /run/user/$UID/aether/ (CONVENTIONS.md §4) and one SQLite/JSON state location under /var/lib/aether/ or the user state dir. Startup dependency graph: hardware-probe and health start early; runtime, intentfs, broker start after; shell and agent start in the graphical session. Units live in system/services/ with hardening directives per unit.
