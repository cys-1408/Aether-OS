# Failure Domains
Principle: ordinary OS function never depends on AI. Per-service behavior: hardware-probe down → shell shows truthful "system status unavailable"; runtime down or model removed → AI features show reasons, Miso switches to rule-based mode; intentfs down → Files uses plain filename search (badge shown); broker down → all agent actions fail closed; ledger down → broker refuses consequential actions rather than executing unaudited; network services down → local use continues, updates/offline; audio/printing absent → controls disabled with reasons. Health maps every failure to user-visible explanation + recovery action (system/health/failure-recovery-map.yaml). Model crash mid-inference → task cancelled, backend marked degraded, desktop unaffected. All services restart on-failure with bounded backoff and publish health state.
