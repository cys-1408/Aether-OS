# Privilege Boundaries
Trusted base: kernel, boot chain, systemd, polkit, the narrowly scoped helpers (/usr/libexec/aether/aether-account-helper, aether-firewall-helper, aether-mount-helper, aether-pm). Each helper validates argv strictly and exposes one narrow verb. Unprivileged services run as dedicated users (identity/service-users.yaml) with systemd sandboxing (NoNewPrivileges, ProtectSystem=strict, SystemCallFilter, empty CapabilityBoundingSet). Miso (aether-agent) runs as the logged-in user with an empty bounding set; it cannot hold root. The broker is the ONLY route from AI-originated intent to privileged operations; it enforces policy at execution time, and the agent cannot alter its own policy files (root-owned, hash-guarded by miso/safety/policy_integrity_guard.py — on mismatch the broker fails closed). Model output is never interpolated into shell strings (miso/safety/no_shell_interpolation.py).
