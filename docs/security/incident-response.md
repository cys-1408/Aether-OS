# Incident Response
Triage within 48 h → severity classify (S1 active exploitation … S4 hardening) → embargoed fix branch → coordinated release + advisory (release notes + SECURITY.md update) → postmortem for S1/S2. Contact: security@aether-os.org; PGP published on aether-os.org. Users are notified of security updates via the update system with user-visible changelog entries.
