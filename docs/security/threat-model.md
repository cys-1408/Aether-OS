# Threat Model
Assets: user data, credentials, model artifacts, ledger integrity, policy integrity, network consent state. Trust boundaries: firmware→boot, kernel→user, user→service sockets (peercred), agent→broker (only privileged route), remote→content (files/web/pages are untrusted). Attack surfaces: prompt injection via indexed content, malicious model artifacts (mitigated by digest+catalog policy), compromised IPC caller (peercred + rate limits), malicious packages (signed repos). Residual risks and scoring live in security/threat-model/risk-register.yaml; incident flow in security/audit.
