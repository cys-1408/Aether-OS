# Miso Artwork
Derived from the approved Aether UI reference (`aether-ui.html`): the base SVG
and state variants (idle/walk/run/jump/sleep/focus/search/carry) preserve the
original path data (body #f8f1e7, markings #a88b73, ears #d4a5a0). Animation
states drive transforms at runtime per theme/motion.yaml; reduced motion
renders the idle frame statically.
